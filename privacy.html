プライバシーポリシー

制定日：2026年10月15日

対象

本ポリシーは「個人用メール送信ツール」（以下「本ツール」）に適用されます。本ツールは開発者本人のみが使用する個人用のツールです。

取得する情報と利用目的

本ツールは Gmail API の gmail.send 権限のみを使用し、開発者本人の Gmail アカウントからメールを送信するためだけに利用します。メールの閲覧・検索・削除は行いません。

保存と第三者提供

  • Google から発行される認証トークンは、開発者本人のコンピューター上にのみ保存します。
  • 取得した情報を外部のサーバーに送信・保存することはありません。
  • 取得した情報を第三者に提供・販売することはありません。

Google API サービスのユーザーデータに関するポリシーへの準拠

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

アクセスの取り消し

本ツールへのアクセス許可は、Google アカウントの「サードパーティ製のアプリとサービス」 からいつでも取り消せます。
